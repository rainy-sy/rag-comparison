Q3

FR500 与 FR510 有什么区别？

返回目录 ↑
题库参考答案（可按原文复核）

FR500 为开环矢量控制变频器，不支持 PG 卡闭环控制和同步电机应用；FR510 为高性能矢量控制变频器，支持 PG 卡闭环控制和同步电机应用，内嵌 FVC 控制。FR510 具备有 PG 矢量控制：调速范围 1:1000、速度控制精度 ±0.1%、0.00Hz 时 180% 启动转矩；而 FR500 无 PG 矢量控制 2 的调速范围为 1:200。

  1. FR510 是 FR500 基础上的增强型产品

    • FR500：开环矢量控制，不支持PG卡闭环控制。
    • FR510：高性能矢量控制，支持PG卡闭环控制。

    • FR500：手册前言明确不支持同步电机应用。

    • FR500：配置对比表中为“通用型变频器”。

结论先说：快捷菜单和基本菜单是操作面板的两种「显示/切换模式」，由 F00.01 功能码显示 控制，它不改变三级菜单结构本身（组→功能码→设定值三级不变），只改变二级菜单里"显示哪些码、怎么切、ESC 怎么走"。

一、什么是快捷菜单（及基本菜单）

  • 快捷菜单（F00.01 = 1）：FR 系列软件 V1.07 及以上出厂默认就是它，"为了便于用户快速设置一般常用参数"。它只显示 F17 组里用户自定义的常用功能码（出厂已预设一组，如 00.03、01.01、01.02、01.08…）。
  • 基本菜单（F00.01 = 0）：完整显示全部功能码，按 F00/F01/F02… 正常顺序浏览。

补充：F00.01 还有第 3 档 = 2（只显示"与出厂值不同的功能码"），用于快速排查改过的参数，但它既不是快捷也不是基本，是独立的一档。

二、两者怎么区分（核心在第二级菜单）

区分维度 快捷菜单（F00.01=1） 基本菜单（F00.01=0）
二级菜单显示 功能码最后一位带小数点，且不闪烁 功能码最后一位不带小数点，且闪烁
▲/▼ 切换逻辑 按 F17 组设定的功能码清单上下切换 按功能码 01、02、03… 全量顺序上下切换
ESC 键行为 不能返回到第一级菜单（组） 可以返回到第一级菜单组（F01…）

三、怎么切换（两种方法，现场都常用）

切到基本菜单

  • 方法 1：把 F00.01 改为 0
  • 方法 2：在二级菜单显示状态下，长按 >>（移位键） 自动切到基本菜单

切到快捷菜单

  • 方法 1：把 F00.01 改为 1
  • 方法 2：在二级菜单显示状态下，长按 >> 键 自动切回快捷菜单

长按 >> 是最快的现场切换手段，不用进 F00.01 改参数。

  3. ESC 的差异要留意：在快捷菜单下误按 ESC 不会退到一级菜单组，按 ▲/▼ 也只在 F17 列表里跳——这是新手常卡住的地方，想回到组级浏览就长按 >> 切到基本菜单。

状态监视参数和故障记录分别在不同的 U 组——

类别 功能码组 组名 说明
状态监视参数 U00 组 状态监视功能组 实时运行数据：设定频率、输出频率、输出电流、电压、转速、功率等
故障记录 U01 组 故障监视功能组 故障/告警记录：故障代码、故障次数、最近故障类别（如前 13 次故障）、故障时的运行参数等

补充几个实用关联点

  1. U00 的具体内容举例：U00.00 设定频率、U00.01 输出频率、U00.05 转速（按 F16.11 系数换算）、U00.35 累计功耗（F00.04=6 可清零）等，范围 U00.00~U00.99。
  2. 面板快捷看 U00：在停机/运行状态下按 >>（移位键）循环显示 4 个监视量，这 4 个内容由 F16.03~F16.06（运行显示）和 F16.07~F16.10（停车显示）从 U00 组里挑选。
  3. U01 故障记录的管理：F00.04=2 可清除 U01 组所有故障信息；F01.14 还引用了 U01.25（前 13 次故障类别）用于故障追溯。
